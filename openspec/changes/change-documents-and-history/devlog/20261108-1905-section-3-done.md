# Section 3 done: rendering and the read APIs

<!-- Section: 3 · Tasks: 3.1–3.3 · Base: a592cbe -->

What landed:
- **3.1:** `Documents/DocumentRenderer`, a singleton.
  - **Extensions picked by hand.** The pipeline isn't `UseAdvancedExtensions()` minus a few. It adds each extension
    explicitly: auto-identifiers, emphasis extras, pipe and grid tables, list extras, task lists, definition
    lists, footnotes, autolinks, plus `DisableHtml()`. The advanced set includes generic attributes
    (`{onclick=…}`) and media links (`<iframe>`).
  - **Link pass after parsing.** For `LinkInline`, images become links (`IsImage = false`; the alt text becomes
    the link's text). A disallowed URL unwraps the link but keeps its text. A disallowed `AutolinkInline`
    becomes literal text.
  - **What's allowed:** `#…`, or an absolute URI whose scheme is `http`, `https` or `mailto`, and that literally
    starts with that scheme and a colon.
  - **YAML** is HTML-encoded in `<pre><code class="language-yaml">`.
  - **Cache:** a `MemoryCache` keyed `md:`/`yaml:` + SHA-256, sized in HTML characters, with a 32M limit.
  - **Tests:** 27, in `tests/.../Rendering/` (`DocumentRendererTests`). They aren't under `Documents/`, because a
    `Panopticon.Server.Tests.Documents` namespace shadows the `Documents.S3Options` used in
    `DashboardEndpointTests`.
- **3.2 and 3.3:** `Changes/ChangePages` (scoped) and `Changes/ChangeEndpoints.MapChanges()`, all behind the
  `Member` policy.
  - **`GET /api/changes/{id:guid}`** returns `ChangePage {card, archivedAt, archiveFolder, documents[{path, kind,
    title, sizeBytes}]}`. The card is the existing `ChangeCard` shape, nested, so the web app can reuse its card
    types.
    - Order: proposal, design, tasks, `specs/*` ordinally, `devlog/*` by file name descending, then everything
      else (meta and other) by path.
    - Titles: the capability for specs (`specs/<cap>/spec.md` → `<cap>`); `slug words · YYYY-MM-DD HH:mm` for
      devlog notes, falling back to the file name.
    - Kinds: `.openspec.yaml`/`.yml` is `meta`. Only files directly under `devlog/` count as `devlog`.
  - **`GET /api/changes/{id:guid}/documents/{**path}`** returns `{path, html}`, or a 404 when the change or path is
    unknown. A listed document whose content is missing from S3 throws (a 500) rather than hiding the problem.
  - **`GET /api/history?before=&limit=`** returns `{changes[{changeId, repo, change, archivedAt, archiveFolder,
    agents}], nextBefore}`.
    - The limit defaults to 50 and must be 1–50, or it's a 400.
    - Sorted by `archived_at` descending, then id.
    - **Paging rule:** the cursor is only the time (D9), so a page backs off before a run of equal times that
      would cross the page boundary. Only a page that is entirely one run ends at the limit, which is documented
      in the code.
- `ChangeCards.Query()` and `ToCard()` are now `internal` for reuse.
