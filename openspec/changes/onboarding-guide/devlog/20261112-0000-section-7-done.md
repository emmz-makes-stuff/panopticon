  say this. Tests cover a root, a path base, a query string and the origin fallback.

  (and `done` is now `doneLabel`).
- **7.5** `CliCatalogue` takes Last-Modified from `File.GetLastWriteTimeUtc(stream.SafeFileHandle)`: the same open
  handle as the hash. The ETag test now asserts a real date (after 2020), not just that one is present.
