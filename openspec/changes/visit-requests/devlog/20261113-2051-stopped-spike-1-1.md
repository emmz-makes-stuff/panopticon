- `server.js` is a node stdio MCP stub with one tool, `request_visit` (`url`, `reason`, optional `action`; no

- `hook.sh` is a sync `PreToolUse` hook. It logs the event to `hook.log` and writes:
  `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"allow","updatedInput":<tool_input minus panopticon_answer, plus {"panopticon_answer":{"outcome":"done","note":"spike note","answeredBy":"Spike"}}>,"additionalContext":"Answered by Spike via Panopticon."}}`
- `.mcp.json` registers the stub as `panopticon`, so the tool is `mcp__panopticon__request_visit`.
- `.claude/settings.local.json` turns on project MCP servers and adds the hook with the matcher
  `^mcp__.*panopticon.*__request_visit$`.
