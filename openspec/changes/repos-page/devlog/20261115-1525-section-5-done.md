## What landed

- **5.1** `RepoActiveChange.Overall` (`CardProgress`) comes from the snapshot in the same query. Tested by
  `RepoEndpointTests.An_active_change_carries_its_whole_change_progress_and_an_archived_one_none`.
- **5.2** Each repo is a card (`.repo` on `--card`). The host is on its own line. Active rows are a grid of name and meta,
  plus `renderProgressBar("Whole change", …)`, stacked under 40rem. Archived rows are `.repo-change--archived`: muted,
  with no bar. The spec has a new requirement, "Active change progress on the Repos page", and design D6 records the
  options offered. DESIGN.md's Repos bullet is rewritten.
- **5.3** `repoLink` appends a decorative SVG arrow (`.external-mark`, `aria-hidden`) and sets
  `aria-label="owner/name, opens in a new tab"`, so `textContent` is unchanged. DESIGN.md's "Repo links" rule mentions it.

## Gotchas

- `perl -0pi` replacements that contain a TypeScript `|` broke two files, because `|` was the delimiter. Use `{}`
  delimiters, or the Edit tool, for union types.
- A `perl` script that reads `$ENV{CSS}` without the variable set replaced a CSS block with nothing. It was restored
  from git, since the deletion was the file's only change.
