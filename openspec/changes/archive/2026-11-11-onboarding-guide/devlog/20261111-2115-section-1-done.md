# §1 done: HEAD and validators on the CLI downloads

<!-- Section: 1 · Tasks: 1.1, 1.2 · Base: 49f6e09 (plan commit) -->

## What landed

- **1.1** `/api/cli`, `/install.sh`, `/install.ps1` and `/cli/{platform}/{file}` use `MapMethods` for GET and HEAD
  (field `_getAndHead`). Before this, a HEAD fell through to the SPA fallback, which takes any method.
- **1.2** `CliBuild` gains `LastModified`: `File.GetLastWriteTimeUtc`, read when the catalogue loads. `Download`
  passes `lastModified` and `entityTag: "<sha256>"` to `PhysicalFile`, which handles `If-None-Match` → 304 itself.
  - Finding: the production ETag wasn't being stripped by Railway. `PhysicalFile` never sent one, because it was
    called without `entityTag` or `lastModified`.
  - The 9.2 comment that overstated this is replaced.

## Gotcha

- **The in-memory `TestServer` sends a body for HEAD; Kestrel doesn't.** The HEAD theory in `CliEndpointTests`
  therefore runs over real Kestrel, with `factory.UseKestrel(port)` and `FreePort.Next()`. Only `PhysicalFile` passed
  in memory, because it handles HEAD itself.
- In the theory, the media-type assertion is the one that would have caught the old app-shell answer (`text/html`).

## Gates

The full run gave `BUILD_EXIT:0` `AOT_EXIT:0` `TEST_EXIT:0` `FORMAT_EXIT:2` `WEB_INSTALL_EXIT:0`
`WEB_BUILD_EXIT:0` `WEB_TEST_EXIT:0` `WEB_FORMAT_EXIT:0` `WEB_LINT_EXIT:0` `VALIDATE_EXIT:0` `GATES_EXIT:2`.
`FORMAT_EXIT:2` was IDE1006: a private static field needs the `_` prefix. After renaming it to `_getAndHead` (the only
change), the reruns gave `FORMAT_EXIT:0` and `BUILD_EXIT:0`.
