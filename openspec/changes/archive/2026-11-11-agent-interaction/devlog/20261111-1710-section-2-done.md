**2.1, contracts** (`src/Panopticon.Contracts/AgentSessions.cs`, `Prompts.cs`, registered in `ContractsJsonContext`):

- `SessionEventRequest(Repo, Change, Machine, SessionId, State, Activity?, Project?)`, `AwayState(Away, Since?)`,
  `SessionLimits.MaxActivityLength = 120`.
- `PromptRequest(Repo, Change, Machine, SessionId, Kind, Questions?, Tool?, Project?)` with `PromptQuestion(Question,
  Header, Options, MultiSelect)` and `PromptOption(Label, Description?, Preview?)`; `PromptCreated(PromptId, Held)`;
  `PromptPreview(Preview)` (the body of `PUT …/preview`, not named in the task but needed); `PromptWaitResult(State,
  Answer?)` with `PromptAnswer(AnsweredBy, Answers?, Allow?, Message?)`.
- **Decision: enums, not string constants** (the device-login contracts use constants). `SessionState`, `PromptKind`
  and `PromptWaitState` each have a `JsonStringEnumConverter<T>` subclass with kebab-case names and
  `allowIntegerValues: false`, so `"sleeping"`, `"3"` and `3` all throw `JsonException` (→ 400 at the endpoint).
  Wire names: `working`, `waiting-on-question`, `waiting-on-permission`, `waiting-on-user`, `ended`; `question`,
  `permission`; `pending`, `answered`, `released`.
- `SessionState` carries the waiting states too, so the CLI can still mark a session waiting when a prompt breaks the
  limits and is never posted ("Huge preview": the card shows it waiting on a question it can't show). `Ended` is how
  `SessionEnd` travels: one endpoint for every state.
- **`PromptLimits.Problem(request)`** is shared by the CLI (5.4) and the server (4.3): ≤4 questions, ≤4 options,
  each preview ≤8 KB, whole request JSON ≤64 KB, and shape checks (a question has questions and no tool; a
  permission has a tool and no questions). `CutPermissionPreview` cuts to 2 KB on a rune boundary.
- Not added: the dashboard's answer body for `POST /api/prompts/{id}/answer` — it's browser → server only; 4.4 adds
  it in the server.
- Tests: `tests/Panopticon.Cli.Tests/AgentContractsTests.cs` (20). Records compare lists by reference, so the
  question round trip compares the levels separately.
