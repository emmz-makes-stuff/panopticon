# Section 2 done: a Project's tags

<!-- Section: 2 · Tasks: 2.1–2.2 · Base: 9f0cf1e -->

**The endpoints:** `src/Panopticon.Server/Projects/ProjectTagEndpoints.cs` (design D3), mapped from `MapProjects` by
`MapProjectTags()`.
- **`POST /api/projects/{id}/tags`** takes `{ tag }` and answers 201 with a `ProjectTagView(Id, Key, Value, Text, ChangeCount)`.
- **`PATCH …/tags/{tagId}`** takes `{ tag }` and answers 200. **`DELETE …/tags/{tagId}`** answers 204, and its
  `change_project_tags` rows go by cascade.
- **Errors:**
  - **400:** the D1 parse error.
  - **403:** "Only the Project's owners and editors can change its tags."
  - **404:** "There's no such Project." for a non-member, and "There's no such tag in this Project." for an unknown
    tag or another Project's tag id.
  - **409:** "PAN/area: onboarding is already one of this Project's tags.", or "This Project has 200 tags, the most
    it can have. Delete one first."
- **Locking:** every write locks the `projects` row with `FOR UPDATE` and checks the role under the lock. A rename to
  an equal tag in other casing is allowed, since the duplicate check excludes the tag itself.
- **`ProjectTagEndpoints.CanManageTags(role)`:** the owner-or-editor test, for §3 to reuse.
  `ProjectEndpoints.RoleAsync` and `NoSuchProject` are now `internal`.
- **The Project page:** `ProjectDetails` gained `Tags` (by `key_key`, then `value_key`, so a bare key sorts first),
  with change counts that include archived changes.

**Live (D6):**
- **The event:** `ChangeEvent.TagsChanged(ProjectId, Tags)`, published by `ChangeBroadcaster.PublishProjectTags`
  after every tag write commits.
- **On the stream:** `StreamAsync` sends it as `project-tags-changed` with
  `ProjectTagsChanged(projectId, tags: [ProjectTagRef(id, key, value)])`, scoped as `ChangeScope(projectId, null)`.
- **`ProjectTagRef`:** in `ProjectTagEndpoints.cs`. It's also the shape §3.1 puts on `ChangeCard.ProjectTags`.

**Tests:**
- **`tests/Panopticon.Server.Tests/Projects/ProjectTagEndpointTests.cs`:** 17 including theory rows. Every role,
  outsiders, malformed tags, duplicates by add and by rename, a rename across changes, a delete taking it off archived
  changes too, the order, cross-Project ids, the 200 limit under a race, and the publish after each write.
- **`ScopedStreamTests`:** +1. Only the Project's members get `project-tags-changed`.

**Gotchas:**
- `CreateSignedInClientAsync(email)` hangs, and then times out, for an address that isn't a member of the server.
  Invite it to some Project first.
- `HttpStatusCode.Created` (201) sorts before `Conflict` (409).

**Gates:** `GATES_EXIT:0` (`BUILD_EXIT:0`, `AOT_EXIT:0`, `TEST_EXIT:0`, `FORMAT_EXIT:0`, `WEB_INSTALL_EXIT:0`,
`WEB_BUILD_EXIT:0`, `WEB_TEST_EXIT:0`, `WEB_FORMAT_EXIT:0`, `WEB_LINT_EXIT:0`, `VALIDATE_EXIT:0`).
