## What landed

- **10.1, saved server and token as a pair:** `BridgeSettings.Resolve` uses the saved token only when
  `SameServer(serverUrl, savedServer)`. That compares scheme, host, port and base path, ignoring case, a trailing `/`
  and `/mcp`.
  - Otherwise `SavedLoginServer` is set, and `RequireServer` throws "PANOPTICON_TOKEN is not set, and this machine's
    saved login is for A, not PANOPTICON_SERVER_URL (B). Run 'panopticon login --server B' …".
  - A malformed env URL still gets the "must be an absolute http or https URL" error, not the mismatch.
  - Updated: the cli-bridge spec (a sentence plus the scenario "Environment server with a login saved for another
    server"), D14 and `docs/cli.md` (config section and troubleshooting).
- **10.2:** the "Token rejected" scenario now names both sources and the fix for each.
- **10.3, `panopticon login`:**
  - A failed `config.Write` (IO or permissions) prints the path and the reason, says to revoke the new token for
    `<machine>` on Tokens, and exits 1.
  - An `HttpRequestException`, or an HttpClient timeout that isn't the user cancelling, while **polling** is retried.
    "Lost contact … Still trying..." is printed once. Once the waited time reaches `expiresInSeconds`, the CLI stops
    and exits 1.
  - A failure on `start` still ends at once, as before.
- **10.4, web:**
  - `takeReturnPath(storage, now, origin)` resolves the path with `new URL(path, origin)`, and refuses `//host`,
    `/\host` and absolute URLs.
  - `safeStorage()` wraps `localStorage` in the shell. Opening it, and every read or write, can't throw.
  - The confirm page shows the server's message for any `ApiError` other than 400.
  - The duplicate `Teardown` comment in `router.ts` is gone.
- **Test fake:** `fakeNavigation` (`web/src/testing.ts`) now throws a `SecurityError` on a cross-origin
  `pushState`/`replaceState`, as browsers do. Before, the `/\evil.example/` test passed even against the old check,
  because the fake quietly moved to another origin whose path is `/`. I checked that it now fails with the old check.
