## What landed

- **11.1, last-member race:** `MemberEndpoints.RemoveAsync` locks every active member row inside its transaction:
  `FromSql("SELECT * FROM members WHERE removed_at IS NULL ORDER BY id FOR UPDATE")`, in id order so two removals
  can't deadlock.
  - The target missing from the locked set is a 404. The remover missing from it is a 409, "You've been removed, so
    you can't remove anyone."
  - Remover active plus target ≠ remover means at least one active member remains, so no count check is needed.
  - Test: `Two_members_removing_each_other_at_once_leave_one_active`, five rounds on fresh servers. One round per
    server is enough, because re-signing in hits the 5-per-address sign-in limit. Without the fix it fails (both
    removals answer 204).
- **11.2, sign-in timing:** `EmailOutbox` now queues `IEmailJob`s, each prepared in its own scope. `SignInLinkJob`
  looks the member up, stores the link and builds the email.
  - `SignInEndpoints.RequestLink` (now synchronous) only validates, rate-limits and enqueues. D8 is updated.
  - Test: `The_request_path_does_the_same_work_for_members_and_strangers`. A `DbCommandInterceptor` counts commands
    issued while `HttpContext.Request.Path` is the sign-in path, through a new `PanopticonFactory.ExtraServices`
    hook. It's 0 now, and 3 against the old handler, which I checked.
  - `A_removed_members_sign_in_request_sends_no_email` now waits on a later member's email: jobs run in order.
- **11.3:** `InitialMembers` catches only a `UniqueViolation`. Test: a CHECK constraint that refuses the seed insert
  fails start-up as a `DbUpdateException` naming the constraint.
- **11.4:** the unused `PublicUrlOptions.Link` is removed.
- **11.5:** `AuthCleanup`, a hosted service and singleton, has `PurgeAsync`. It runs at start, then hourly, with a
  `PeriodicTimer` on the injected `TimeProvider`. It deletes sessions, sign-in links and device logins expired more
  than a day ago, and keeps API tokens and members. D19 is a new "Housekeeping" heading in `design.md`. Test:
  `AuthCleanupTests`.
