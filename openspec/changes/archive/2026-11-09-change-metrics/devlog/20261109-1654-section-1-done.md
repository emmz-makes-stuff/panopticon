**1.1:**
- **Migration `20261109164834_ChangeMetrics`:**
  - nullable `overall_done`, `overall_total` and `current_section` on `report_events`;
  - `sections` (jsonb), mapped as an owned JSON collection (`OwnsMany(...).ToJson("sections")`), the same pattern
    as `changes.snapshot`;
  - a partial index `ix_report_events_progress_pending` on `id WHERE overall_total IS NULL`, for the backfill.
- **Filling the columns:** `Progress/ReportProgress.Fill` is shared by `ReportRecorder` and the backfill.
  `MarkUnreadable` stamps `ReportEvent.Unreadable` (-1).
- **Decision: `current_section` is stored only when the current section is numbered.** A section numbered by its
  position could share a number with an explicitly numbered one, and unnumbered sections aren't measured (spec).
  The same goes for `sections`, which holds `IsNumbered` sections only.

**1.2: `Progress/ProgressBackfill`.**
- **How it runs:** a singleton `BackgroundService`, registered in `ServerSetup`. It runs once on start, after
  `Task.Yield`, so start-up isn't held. It is never started in `--migrate` mode, and `Program.cs` migrates before
  `app.Run`.
- **Testing:** the public `RunAsync` returns `BackfillResult(Filled, Unreadable, Stopped)`, so tests drive it with
  their own small `ServiceProvider`. That avoids racing the hosted run.
- **Batches:**
  - 200 rows per batch, `WHERE overall_total IS NULL AND id > afterId ORDER BY id`;
  - `tasks.md` is fetched and parsed once per hash per batch.
- **When `tasks.md` can't be read:** a null `GetAsync` (missing object), or a `TasksDocumentTooLargeException`
  (the only way the parser can fail), marks the event unreadable. A warning names the event id and the hash.
- **Any other store exception** saves the batch's progress so far, logs a warning ("stopped at report event N"),
  and returns `Stopped: true`. The next start retries.
- **Failures elsewhere:** `ExecuteAsync` logs any other failure. Since .NET 8, a hosted service's exception stops
  the host, so it mustn't escape.

**Tests:**
- **Recorder:** counts and numbered sections only; a current section numbered by position isn't kept.
