Emmz chose short visible text ("5d 6h", "3h 30m", "45m") with the long form ("5 days 6 hours") as a tooltip and as

**3.1:**
- **`types.ts`:** `SectionMetric`, `ChangeMetrics`, `WeekMetric`, `SlowSection`, `TeamMetrics`.
- **`api.ts`:** `fetchChangeMetrics(api, id)` and `fetchMetrics(api, filters = "")`. The filters are a query string
  from `toQuery`, as with `fetchHistory`.
- **`format.ts`:**
  - **`formatDuration`:** the two largest units, the smaller left out when it's 0 ("3h", "5d"). It reads "<1m" under
    a minute, and negative counts as 0.
  - **`formatDurationLong`:** "less than a minute", "1 minute", "3 hours 30 minutes", "5 days 6 hours".

**3.2:**
- **`metricsPanel.ts`:**
  - `durationText(seconds)` is a span: the short text `aria-hidden`, plus a `.visually-hidden` long copy, with the
    long form as `title`. **Reuse it on the metrics page.**
  - `renderChangeMetrics` gives:
    - "Took …" or "Running for …";
    - a note: "Wall-clock time, first report to archive." (D5 risk) or "…since the first report.";
    - an `ol.metrics-sections` (number, title, time), or "No section has been started yet.";
    - for a row in progress, `li.in-progress` with "in progress · 1h so far".
- **`views/change.ts`:**
  - `section.change-metrics` (aria-label "Metrics") sits between the header and the archived status.
  - It loads with the page without blocking the documents, and loads again in `refresh()` (on change-updated,
    change-archived and reconnect). It has its own ticket, which teardown bumps.
  - **On failure:** "Couldn't load this change's metrics." It isn't `role="alert"`, since other tests count alerts.
    The panel keeps what it shows if it already has content, and a 401 is left to the shell.
- **`styles.css`:** only `.visually-hidden` for now. The panel's real look is §5.1's `frontend-design` pass.
- **Tests (`views/change.test.ts`, "change page metrics", 5):** archived, active with a section in progress, live
  while open, no measured sections, and a failed load. Existing tests answer the metrics call with the fake
