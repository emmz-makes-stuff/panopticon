# §3 done: quiet cards (web)

Base `94cca05`.

## What landed

- **`web/src/quiet.ts`:**
  - `QuietState` (`active`, `idle`, `stale`), `QuietSettings` (`idleAfterSeconds`, `staleAfterSeconds`) and `DEFAULT_QUIET` (1800/14400).
  - `quietState(lastReportedAt, now, settings)`: a card goes idle when it's *older than* the idle threshold, so exactly 30 min is still active; stale works the same way. A future timestamp is active.
  - `isQuietSettings(value)`: both thresholds must be positive and stale must be longer than idle.
- **Shell (`Env.quietSettings()`):**
  - It's memoized and prefetched right after a successful session check. Signed out, it isn't asked for; after a later sign-in, the cards view's first call fetches it.
  - It never rejects. A failed or nonsensical answer gives `DEFAULT_QUIET` with a `console.warn` and clears the memo, so the next view mount asks again.
- **`card.ts`:**
  - **Markup:** `renderCard(card, now, quiet = DEFAULT_QUIET)`. The repo line's right side is now `span.card-when`, holding `span.card-state`, then `span.card-state-separator` (" · ", `aria-hidden`), then `time.card-time`.
  - **`applyQuiet(article, card, now, quiet)`:**
    - toggles `card--idle`/`card--stale` and sets `data-quiet`;
    - names the state in the label ("Idle"/"Stale"; label and separator `hidden` when active);
    - sets the time text, with "last seen 5h ago" when stale;
    - returns the state, which §4's status filter can use.
- **`app.ts`:** `AppDeps.quiet` goes to every `renderCard`, and `updateTimes()` now runs `applyQuiet` on every card (the 30 s tick in `views/cards.ts`). A new report re-renders the card, so it's active again.
- **CSS:** only `.card-when` takes the old `.card-time` text style, and `.card-state` is bold. The real idle and stale look is §6.
- **Tests:**
  - `quiet.test.ts`: boundaries and settings validation;
  - `app.test.ts`: the five spec scenarios, plus custom thresholds;
  - `shell.test.ts`: settings fetched once and used, the failure fallback with the warning, and nothing asked for before sign-in.
  - `testShell.signedIn()` now answers `/api/settings` too.
