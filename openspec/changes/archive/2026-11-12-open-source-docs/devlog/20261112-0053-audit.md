## Findings to decide on

1. **A personal email address in an archived devlog.** The maintainer's personal Gmail address is named as PAN's
   owner in
   `openspec/changes/archive/2026-11-11-agent-interaction/devlog/20261111-2235-section-8-done.md`, line 19. It came in
   with commit `db196c0` (2026-11-11). *Suggested:* replace it in that file (for example with "Emmz's own account")
   before going public. The archive is otherwise out of scope, so this change leaves it. Git history keeps it unless
   history is rewritten.
2. **Commit identities.** 167 commits are authored and committed as `Rendle` with the same personal Gmail address. The
   8 merge commits are `Emmz Rendle`, committed by `GitHub`. Once the repo is public, anyone can read these with
   `git log`. *Suggested:* either accept that, or rewrite them before going public with `git filter-repo --mailmap`.
   A rewrite changes every SHA and the existing tags (`v0.3.0` and earlier), and needs a force push. Separately,
   setting `user.email` to the GitHub noreply address for this repo keeps it out of future commits.
3. **The machine name and username in archived devlogs.** `Rendles-MacBook-Pro` appears in 6 archived devlog notes
   (it's how an agent is labelled on the cards). The username `rendle` appears in local paths
   (`/Users/rendle/…`, `/private/tmp/claude-501/-Users-rendle-…`) in 4 of them. *Suggested:* fine to leave (low
   sensitivity), or replace it along with finding 1.
