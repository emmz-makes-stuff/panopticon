## What landed

- **`CliVersion`** (`src/Panopticon.Cli/CliVersion.cs`) has two properties. `Informational` is the assembly's
  informational version, which the SDK suffixes with `+<commit>`. `Current` is the same without that suffix, through
  `WithoutBuildMetadata`. `BridgeHost.Version` now reads `CliVersion.Informational`, so the MCP server info is
  unchanged. There's one source for the version.
- **`panopticon --version`** (and `version`) prints `CliVersion.Current` and exits 0. It's in `--help`.
- **`Panopticon.Cli.csproj`** sets `<Version>0.0.0-dev</Version>`. Release builds override it with
  `-p:Version=X.Y.Z` (D5).
- **Checked by hand:** `make aot` → `artifacts/cli/panopticon --version` prints `0.0.0-dev`, and
  `dotnet publish … -p:Version=0.2.0` gives a binary whose `--version` prints `0.2.0`.
