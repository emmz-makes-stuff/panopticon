## Summary

The server hands out the CLI:
- `/api/cli` returns the manifest;
- `/cli/<rid>/<file>` returns the builds;
- `/install.sh` and `/install.ps1` are rendered per request.

The builds are bundled in the image from the release that deployed it. `panopticon --version` and `panopticon update`
keep a machine on its server's build. The Tokens page shows the install command. A `v*` tag builds the CLI for four
platforms, publishes a GitHub Release with `SHA256SUMS`, and deploys.
