**The blocker:** every dotnet gate failed at restore with

```
error NU1903: Warning As Error: Package 'Microsoft.DotNet.ILCompiler' 10.0.11 has a known high severity
vulnerability, https://github.com/advisories/GHSA-p3jp-9v83-76w9
BUILD_EXIT:1  TEST_EXIT:1  FORMAT_EXIT:1  AOT_EXIT:1
```

SDK 10.0.400 adds the AOT compiler pack 10.0.11 to the CLI project (`PublishAot`). 10.0.11 is also the
newest .NET 10 runtime on this machine. Homebrew offers SDK **10.0.403**. **Emmz chose to install
10.0.403 herself and restart the session.** The other options (pinning ILCompiler, suppressing NU1903)
were rejected.

**Gotchas:**

- `make test`, `make gates` and `dotnet package search` must run unsandboxed (the Docker socket and
  nuget.org are blocked in the sandbox).
- Before `global.json` existed, the 11 RC SDK was selected and rejected `dotnet test --solution`.
