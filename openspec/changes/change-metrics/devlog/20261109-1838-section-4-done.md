**4.1: `charts.ts`.**
- **`renderBarChart({ title, bars, formatValue, columns, noValue })`:** a `figure.chart` holding two things:
  - **The SVG** (`svg.chart-svg`, `role="img"`): `rect.chart-bar` bars, a `.chart-label` under each, the largest
    value as `.chart-scale` at the top, and a `line.chart-axis` baseline. Its viewBox is 24 units per bar by 132,
    with no `preserveAspectRatio="none"`, which would stretch the text.
  - **The table** (`table.visually-hidden.chart-table`): a caption, headings, and one row per bar, with `noValue`
    for null.
- **`barHeights`:** each bar relative to the largest, out of `PLOT_HEIGHT` (100). Null or 0 gives no bar, and any
  value above 0 is at least 1, so it stays visible.
- **`chartSummary`:** "<title>: N of M with a value, the largest X (label)." It falls back to "no values to show".
- **Colours:** none are set in `charts.ts`. Classes only, so §5.1 styles the fill (`--lit`) and the text
  (`--ink-muted`).

**4.2: `views/metrics.ts`, a route in `shell.ts`, and a Metrics link after History.**
- **Like the history:** `HISTORY_KEYS`, `createFilterBar`, the choices from `/api/history/filters`, and
  `navigate("/metrics?…")` on a change. `update(params)` reloads in place, guarded by a generation ticket.
- **What it shows:**
  - `dl.metrics-figures`: changes archived, the median time to archive, and the median time per section ("No
    finished sections" when there's none);
  - `section.metrics-weeks`: the chart, with weeks labelled "2 Nov" (UTC, `weekLabel`) and a note on what a week
    is;
  - `section.metrics-slowest`: an `ol` of "Section N: title", then a change link (`changeHref`), then
    `owner/name`, then `durationText`;
  - a wall-clock note.
- **Empty states:** filtered with nothing matching, `noMatch(...)` with Clear filters, which navigates to
  `/metrics`. Nothing archived at all: "No changes have been archived yet."
- **On failure:** the `alertLine` shows the server's detail, and a "Try again" button (class `show-more`, as in the
  history) loads again.
- **Removed in self-review:** an `aria-live` on the body, which would have read the whole page aloud on every
  filter change. The history doesn't have one either.
- **The server needed nothing:** `MapFallbackToFile` serves every non-api path, `/metrics` included.
