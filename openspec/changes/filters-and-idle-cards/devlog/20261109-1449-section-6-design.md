# §6 done: design pass (filter bar and quiet cards)

Base `97f5e36`. This used the `frontend-design` skill, within `web/DESIGN.md`. The new section is "Filters and quiet cards".

## Choices

- **Idle:** the change name and owner/name drop to `--ink-muted`, with "Idle" in `--ink` 600. The lit cells stay teal, since progress is still worth reading.
- **Stale:**
  - **The surface:** a `--paper` background, a dashed border (`--ink-muted` 45% into `--rule`, so the edge still shows), and muted text and pills.
  - **The cells:** they turn `--ink-muted`, so a stale card holds no teal.
- **No 60% opacity:** this replaces the opacity DESIGN.md had for stale cards, since it put text below the 4.5:1 floor, and I updated DESIGN.md's colour note to match. **Worth Emmz's eye in 7.2.**
- **The separator:** "Idle, 1h ago" and "Stale, last seen 5h ago" use a comma instead of the design's "·". DESIGN.md principle 5 bans middot-joined meta, so design D2's wording lost here. The comma is no longer `aria-hidden`.
- **Filter bar:**
  - **Layout:** a flex-wrap row, with each select labelled above (as on the forms) and a 4px radius.
  - **A set filter:** `filter-select--set`, a 2px `--ink` border and 600 weight, so it shows by shape and weight, not colour. `filterBar.ts` toggles the class.
  - **The rest:** "Clear filters" is a link button at the end of the row, and the dropped-filter note is a muted full-width line.
- **On a phone (max-width 40rem):** the selects pair up two to a row, with no "Filters (2)" toggle (the design's D7 option), so what's chosen stays in sight.
- **No match:** the empty state's type (Gabarito 700, 25px), a muted line, and a link button.
